# ION TILT

Full-colour Python 3 neon pinball arcade for [ElbowOS](https://x.com/ElbowOS).

Keep the gold ion ball alive on a violet table. Z / Left and X / Right fire the flippers. Bumpers, slings and spin targets stack score until the drain.

## Play

```
pip install -r requirements.txt
python3 ion_tilt.py --play
```

## Record a 9:16 reel

```
python3 ion_tilt.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.

* Featured account: https://x.com/ElbowOS
